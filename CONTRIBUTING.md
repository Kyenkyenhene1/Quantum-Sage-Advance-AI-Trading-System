# Contributing

Thanks for considering contributing. Quick starter steps:

1. Fork the repo and create a feature branch.
2. Install dependencies: `npm ci`.
3. Run linters and typechecks: `npm run lint` and `npm run typecheck`.
4. Run tests: `npm run test` (after installing dev dependencies).
5. Open a PR against `main` with a clear description and tests if applicable.

Please avoid committing secrets — use `.env.local` and follow the `.env.example`.
